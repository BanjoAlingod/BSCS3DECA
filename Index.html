🎓 What Students Should Learn

A brute-force attack attempts possible passwords or PINs until the correct combination is found.


A 4-digit PIN has only 10,000 possible combinations, from 0000 to 9999.


Increasing password length dramatically increases the number of possible combinations.


Security mechanisms such as rate limiting, account lockout, and stronger passwords make brute-force attacks more difficult.
