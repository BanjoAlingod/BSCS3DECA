🎓 What Is SQL Injection?

SQL Injection occurs when an application places untrusted user input directly into an SQL statement without properly separating data from SQL commands.


In this simulation, the vulnerable application constructs a query using user-provided text.


The secure version demonstrates the principle of using parameterized queries instead of treating user input as part of the SQL command.


Try the demonstration input shown in the activity below, then switch to Secure Mode and observe the difference.

📝 Student Activity

Task 1: Log in using the normal credentials displayed in the simulated database.


Task 2: Experiment with specially crafted input in Vulnerable Mode.


Task 3: Observe the generated SQL query and explain how the input changes the intended query logic.


Task 4: Switch to Secure Mode and repeat the experiment.


Question: Why does parameterized SQL prevent the user input from becoming part of the SQL command?
